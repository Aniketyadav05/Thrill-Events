## 🌀 What is Thrill Events?

> **Thrill Events** is a stylish, user-friendly event management web app where users can explore and plan events effortlessly. Built using **React**, **Tailwind CSS**, and **Framer Motion** for smooth transitions.

---

### ✨ Features

- 🗓️ Browse upcoming events by type  
- 🔍 Smooth scroll navigation  
- 🌟 Attractive animations with Framer Motion  
- 📱 Fully responsive design  
- 🔗 Clean and modern UI layout

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Aniketyadav05/Thrill-Events.git

# Navigate to the directory
cd Thrill-Events

# Install dependencies
npm install

# Start the development server
npm run dev
````
